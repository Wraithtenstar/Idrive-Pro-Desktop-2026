## Features

- Automatic scheduled backups of selected files, folders and entire drives
- Block-level incremental uploads that only transfer changed portions of files
- 256-bit AES encryption with an optional private key known only to you
- Snapshot-based versioning for point-in-time restore and ransomware protection
- Restore, share and manage backed-up data from any browser or mobile device
